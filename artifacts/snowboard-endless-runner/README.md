# Powderline

An original, static-friendly downhill snowboarding endless runner.

## Play

- **A / D** or **Left / Right**: steer
- **Space / Enter**: start or restart
- Collect beacons to build a chain
- Avoid trees and rocks

The best score is saved locally in the browser. No account or server is required.

## GitHub Pages

Build the app with Vite and publish the generated `dist/public` directory as the Pages artifact. For a repository project site, configure the Vite base path to the repository name before building so asset URLs are prefixed correctly.

The Pages URL for the published repository is:

`https://t1win-oss.github.io/powderline/`

After publishing:

1. Add the URL as a property in Google Search Console.
2. Verify ownership using the HTML tag, HTML file, or DNS method Google provides.
3. Submit `/powderline/sitemap.xml` in Search Console.

The app already includes crawlable title/description metadata and `robots.txt`.
